## Nghiên cứu (20/11)
- Claude web, desktop và app điện thoại dùng MCP từ xa qua "custom connector": thêm bằng link máy chủ, có ở mọi gói kể cả Free; gói Free chỉ được một connector tự thêm. - Giấu được và lộ gì (20/11): logic MCP chạy phía máy chủ, không qua ranh giới (https://dev.to/mogwainerfherder/dont-lose-your-ip-through-your-mcp-3e3e); tên và mô tả công cụ thì vào ngữ cảnh model (https://www.redhat.com/en/blog/mcp-security-logging-and-runtime-security-measures), kết quả trả về cũng vậy.
- MCP Apps (phần mở rộng chính thức đầu tiên, 26/01/2026): công cụ trả giao diện tương tác hiện ngay trong chat, Claude web và desktop đã hỗ trợ. Nguồn: https://blog.modelcontextprotocol.io/posts/2026-01-26-mcp-apps/
- Hướng khác đã xét: skill chia sẻ cần gói Team, người nhận không sửa được nhưng Claude đọc được file (https://support.claude.com/en/articles/12512180-use-skills-in-claude); plugin là file, lên danh mục thì repo phải public (https://www.claude.com/docs/plugins/submit); Project chia sẻ cần Team, người xem thấy cả hướng dẫn và tài liệu (https://support.claude.com/en/articles/9517075-what-is-a-claude-project); repo public lộ hết; web app riêng gọi API giấu kỹ nhất nhưng tốn tiền API và nhóm phải rời Claude.
