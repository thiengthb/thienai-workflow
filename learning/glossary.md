# Glossary: từ khóa

Bảng tra thuật ngữ tiếng Anh thien gặp khi làm và học với AI. AI thêm một dòng ngay lần đầu dùng một từ mà thien chưa học (luật ở mục "Thuật ngữ tiếng Anh" trong `profile/VOICE.md`). Khi quên, thien tra ở đây trước, không cần hỏi lại.

Cột "Đã quen" để thien tự đánh dấu. Từ đã quen thì AI chỉ viết tiếng Anh, không kèm bản dịch nữa.

| Từ | Nghĩa ngắn | Gặp lần đầu | Đã quen |
|---|---|---|---|
| PR (pull request) | yêu cầu gộp phần code mình sửa vào nhánh chính, để người khác xem trước | | |
| merge | gộp code từ nhánh này vào nhánh khác | | |
| review | đọc và góp ý code hay tài liệu trước khi gộp | | |
| cache | bản lưu tạm để lần sau mở nhanh hơn; cũ thì có thể hiện sai | 08/11/2026, vòng chấm giọng văn | |
| component | một mảnh giao diện viết một lần, dùng lại nhiều chỗ | 08/11/2026, vòng chấm giọng văn | |
| state | dữ liệu một component đang giữ, đổi thì giao diện đổi theo | 08/11/2026, vòng chấm giọng văn | |
| re-render | vẽ lại giao diện khi dữ liệu đổi | 08/11/2026, vòng chấm giọng văn | |
